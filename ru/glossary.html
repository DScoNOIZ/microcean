Глоссарий Microcean

Ключевые термины концепции в алфавитном порядке. Термины-англицизмы оставлены на английском там, где это общепринято в профессии.

Агент (Agent)
Автономный программный исполнитель, решающий узкую задачу (оценка фрагмента, поиск конфликта, сборка). В Microcean сборку выполняет рой узких агентов, а не один универсальный ИИ.
Архипелаг (Archipelago)
Метафора современного ландшафта ПО: разрозненные острова (репозитории, пакеты, IDE, CI/CD), слабо связанные мостами. Microcean предлагает Океан — сплошную воду вместо архипелага.
Библиотеки и пакеты (Libraries/Packages)
«Крупные обитатели» Океана — киты и коралловые рифы. Зрелые формы, отточенные эволюцией; используются целиком, копируются, приручаются. Но фундамент жизни — планктон микро-фрагментов.
Версионирование / Осадочные слои (Version History / Sedimentary Layers)
История изменений в Океане не теряется — она оседает на дне как геологические слои. Любая версия любого фрагмента доступна для аудита и повторного использования.
Гранулярность / Отсутствие жёсткой градации (Granularity / No Rigid Gradation)
Планктон (микро-фрагменты) → стаи рыб (функции/модули) → острова (пакеты/приложения) → экосистемы (стэки). Нет чётких границ — берёшь ровно то, что нужно: капли, стаю, остров.
Двухдатная цепочка (Two-Date Chain)
Внутренняя фиксация 2026-08-11 в рабочих материалах концепции + публичное раскрытие 2026-10-22 в GitHub. История коммитов = проверяемое доказательство даты.
Доверие без блокчейна (Trust Without Blockchain)
Репутация через исполняемые тесты + лёгкие консенсусные алгоритмы (PBFT, Raft). Никакого энергозатратного PoW — доверие зарабатывается делом.
Защита от Sybil (Sybil Resistance)
Douceur 2002: без внешней идентификации невозможно. В Microcean: экономическая ставка (стейк) на входе в океан + репутация на графе цитирований фрагментов, а не на узлах.
Закон Амдала (Amdahl's Law)
Параллелизм ограничен последовательной долей координации. E8: при p=0,99 потолок ускорения на 1024 ядрах = 91,2× (предел 100×).
Колмогоровская сложность K(x)
Минимальная длина программы, производящей x. Невычислима (Solomonoff 1964; Li & Vitányi 2008). «Ноль лишнего» — эвристика через MDL, не математический оптимум.
Кембрийский взрыв (Cambrian Explosion)
Метафора: как в океане жизни — внезапное разнообразие форм. В Океане кода — когда фрагменты начинают комбинироваться свободно, рождается взрывное количество новых программ.
Клиент (Client)
Программа, подключающаяся к протоколу Океана. Множество клиентовwelcome; нет vendor lock-in, нет API-ключей на уровне протокола.
Колмогоровская сложность K(x)
Минимальная длина программы, производящей x. Невычислима. «Ноль лишнего» — эвристика через MDL, не математический оптимум.
Компрометация (Compromise)
Атака на фрагмент. В Океане: нет монокультуры — компрометация одного фрагмента не разрушает систему; весть об угрозе расходится по течениям.
Координация (Coordination)
Последовательная часть сборки, задающая потолок параллелизма по закону Амдала. Верхний уровень управления роем.
Лагуна (Lagoon)
Закрытый контур организации/государства: свои фрагменты, своя история, ноль утечек. Самодостаточна, но без притока извне беднее. Возможен выборочный обмен (мост) и форк экосистемы.
Математический аппарат / Навигация (Mathematical Apparatus / Navigation)
Формальная модель (ℱ, сборка, целевая функция Φ), теоремы (схема Холланда, уравнение Прайса, GDC sizing, NFL, Амдал, Райс), эксперименты E1–E10 с seed=42.
Микро-фрагмент (Micro-fragment)
Основная единица кода — небольшой фрагмент (функция, алгоритм) с интерфейсом, пред-/постусловиями, хешем, репутацией, семантическими тегами, измеренным профилем производительности. Не крупный пакет.
Мост (Bridge)
Избирательный обмен между лагуной и открытым Океаном по правилам владельца лагуны: что-то ввозится, что-то никогда не покидает контур.
МДL / Minimum Description Length
Принцип Риissanена 1978: L(D) = min_H [L(H) + L(D|H)] — формализация бритвы Оккама. В Microcean: штраф за размер сборки в целевой функции; E10: сборка в 2,5× короче при корректности 1,0.
Ноль лишнего (Zero Excess)
Принцип: не тащить за собой то, что не используется. Базовая единица повторного использования — фрагмент ровно нужного размера. Тесты эффективности равноправны тестам корректности.
Океан (Ocean)
Единая среда, где живёт всё ПО планеты: код, история, практики. Обмен, работа, хранение, передача — соседние области одного моря. Не архипелаг.
Планктон (Plankton)
Метафора микро-фрагментов: мельчайшие, самые многочисленные, фундамент всей пищевой цепи Океана. Из миллиарда капель — одна вода.
Потоки / Течения (Currents)
Движение фрагментов между участниками. P2P-слой на Kademlia (O(log n) поиск) + Gossip push-pull (O(log n) распространение обновлений).
Природа / Эволюция (Evolution / Evolutionary Selection)
Варианты сборки конкурируют; лучшие комбинации сохраняются и развиваются — по принципам эволюционной биологии и генетических алгоритмов. Элитизм + рестарты смягчают отсутствие гарантии сходимости.
Приоритет / Defensive Prior Art
Публикация концепции (2026-08-11/10-22) создаёт prior art: никто не может запатентовать раскрытое. CC0 1.0 Universal + ст.1265/1267 ГК РФ (неотчуждаемое авторство).
Проба (Lookup / Kademlia)
Поиск фрагмента в сети 10⁹ узлов: среднее 5,42 ± 0,83 хопа (E5), максимум 8. Верхняя граница ceil log₂ n = 30.
Пропускная способность / Пропускная способность (Throughput)
Пропускная способность Океана ограничена законом Амдала: последовательная координация/верификация задаёт потолок параллелизма.
Прозрачность (Transparency)
Все фрагменты, их история, репутация, тесты — открыты и проверяемы. Никаких черных ящиков.
Репутация (Reputation)
История пройденных исполняемых тестов + ресурсный профиль. Репутация фрагмента накапливается на графе цитирований; репутация автора — через качество его фрагментов.
Рой (Swarm)
Множество узких специализированных исполнителей (нейросетевых и алгоритмических). Каждый решает одну задачу. Модели высокого класса — точечно, там где нужно понимание смысла.
Сборка (Assembly)
Подмножество фрагментов S ⊆ ℱ с операцией композиции ∘, склеивающей их в программу p. Цель: argmin Φ(S) = α·Err + β·cost + γ·incomp.
Синтез по спецификации / CEGIS
Counterexample-Guided Inductive Synthesis (SyGuS, Alur et al. 2013). Цикл «синтезатор–верификатор»: soundness доказана; завершаемость при конечной грамматике доказана; полнота в общем случае недостижима.
Смарт-контракт / Queue-of-Rights
Неизменяемая история прав на фрагмент в CRDT (ORSet для мульти-авторства). Операционная трансформация при конфликтах. Queue-of-rights = закон в коде.
Стейк / Stake
Экономическая ставка на корректность фрагмента при публикации. Защита от Sybil и фрагментного мусора. Сжигается при обнаружении вредоносности.
Стаи рыб (Schools of Fish)
Метафора функций/модулей: группы фрагментов, работающих согласованно. Больше планктона, меньше островов.
Течение знаний (Knowledge Currents)
Решение, найденное на одном берегу, доходит до другого. Практики и паттерны распространяются эпидемически (Gossip).
Форк экосистемы (Ecosystem Fork)
Перенос подходящей открытой системы целиком в свою лагуну для доработки под свои задачи. Как пересесть ручей в свой пруд.
Целевая функция Φ (Objective Function)
Φ(S) = α·Err(S, Spec) + β·cost(p(S)) + γ·incomp(S). α ≫ β, γ. cost = полный ресурсный след: размер, время, память, трафик, энергия.
Черновик / Working Materials
Внутренние материалы концепции, где зафиксирована дата 2026-08-11. Не путать с публичным раскрытием 2026-10-22.
Штаммы / Strains
Варианты одного фрагмента с разными оптимизациями/исправлениями. Эволюционный отбор выбирает лучшие штаммы.
Экосистемы (Ecosystems)
Метафора полных стэков: совокупность островов (пакетов/приложений), живущих в симбиозе. Крупная форма жизни в Океане.
Эпистазия (Epistasis)
Взаимодействие между фрагментами. λ ≤ 0,3 → корректность 1,0; λ = 0,7 → 0,325 (E3). Требование «чистых интерфейсов» — архитектурный ответ.
Юридическое положение (Legal Standing)
CC0 1.0 Universal; неотчуждаемое авторство (ст.1265/1267 ГК РФ); defensive prior art; автор не оператор/не бенефициар/не учредитель; тройное датирование (DOI/OTS/нотариус) — в подготовке.
Якоря / Anchors (Anchor References)
Ссылки на фрагменты внутри сборки (ref, multi_ref, transform). Позволяют агенту сослаться на готовый кусок вместо регенерации.
