# MICROCEAN

Concept site for **MICROCEAN** — a plan for a planetary self-assembling software
ecosystem ("an ocean of code made of a billion drops"). The concept symbol is a
wave made of dots (see `favicon.svg`).

Static HTML5, no build system, no JavaScript dependencies, Russian-language
content. Pages:

| Page | Audience |
|------|----------|
| `index.html` | Hub / navigation for all levels |
| `ru/vsem.html` | General readers |
| `ru/specialistam.html` | Software engineers |
| `ru/uchenym.html` | Scientists (formal model, experiments E1–E10) |
| `ru/filosofiya.html` | Philosophy of the concept |

Full publication text and reproducible experiment scripts (EXP1–EXP10) live in
`research/`; the complete one-pager is `research/report.md`.
